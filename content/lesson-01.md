# 01. Вступ / Introduction

## Українська

### Навчальна мета
Після завершення цього блоку слухач зможе пояснити, що таке глибоке навчання, чим воно пов’язане з машинним навчанням і чому нейронні мережі корисні для роботи зі складними даними.

### Що таке Deep Learning?
Глибоке навчання (Deep Learning) — це підхід у машинному навчанні, що використовує багатошарові штучні нейронні мережі для виявлення закономірностей у даних. Замість того щоб вручну задавати кожну ознаку, модель може навчатися корисних представлень безпосередньо з прикладів.

### Чому це важливо?
Глибоке навчання особливо корисне там, де дані складні та великі: зображення, відео, мовлення, текст і сигнали. Воно лежить в основі багатьох сучасних систем комп’ютерного зору, розпізнавання мовлення та обробки природної мови.

### Ключова ідея
**Дані → Нейронна мережа → Навчання → Результат**

Мережа отримує приклади, робить прогноз, порівнює його з очікуваним результатом і коригує внутрішні параметри. Багаторазове повторення цього циклу поступово покращує результат.

## English

### Learning objective
After completing this section, the learner will be able to explain what deep learning is, how it relates to machine learning, and why neural networks are useful for complex data.

### What is Deep Learning?
Deep Learning is an approach within machine learning that uses multilayer artificial neural networks to discover patterns in data. Instead of manually defining every feature, a model can learn useful representations directly from examples.

### Why does it matter?
Deep learning is particularly useful for complex and large-scale data such as images, video, speech, text, and signals. It underpins many modern systems for computer vision, speech recognition, and natural language processing.

### Key idea
**Data → Neural Network → Learning → Result**

The network receives examples, makes a prediction, compares it with the expected result, and adjusts its internal parameters. Repeating this cycle gradually improves performance.
